# 🎮 Mario Game

A browser-based Mario-inspired platform game built using **HTML, CSS, and JavaScript**.

The project focuses on creating a simple interactive 2D gaming experience that runs directly in the browser.

## 🌐 Live Demo

🎮 **[Play the Game](https://adyasa28.github.io/Mario-game/)**

## ✨ Features

- 🎮 Browser-based gameplay
- 🏃 Character movement
- ⌨️ Keyboard controls
- 🧱 Platform-based level design
- 🎨 Custom CSS styling
- ⚡ JavaScript game logic
- 🌐 Runs directly in the browser
- 💻 Lightweight and easy to run

## 🛠️ Built With

| Technology | Purpose |
|---|---|
| **HTML5** | Game structure |
| **CSS3** | Styling, layout and visual design |
| **JavaScript** | Game logic and interactions |

## 📂 Project Structure

```text
Mario-game/

```

🚀 How to Run Locally
1. Clone the repository
git clone https://github.com/Adyasa28/Mario-game.git

2. Open the project
cd Mario-game

3. Run the game

Open index.html in your browser.

For a better development experience, you can use the Live Server extension in VS Code.
